# Utility Tools

A collection of simple, fast, and free web-based utility applications for solving common daily tasks.

🌐 **Live Demo:** https://akshay43215.github.io/utility_apps/

---

## About

Utility Tools is a curated collection of lightweight web applications designed to help you with everyday productivity and utility needs. From text comparison to image processing, gaming to web communication—all built with pure HTML, CSS, and JavaScript.

## Features

- ⚡ **Lightning Fast** - No heavy dependencies, instant loading
- 🌐 **Browser-Based** - Works on any modern browser (desktop, tablet, mobile)
- 🎯 **Simple & Intuitive** - Easy-to-use interfaces for everyday tasks
- 🔓 **Free & Open Source** - No ads, no paywalls
- 📱 **Responsive Design** - Optimized for all screen sizes

---

## Available Tools

### 🎮 Gaming & Entertainment
- **Puzzle Game** - Test your puzzle-solving skills
- **Coin-Flip & Lucky-Spinner** - Quick randomization tools for games and decisions

### 🖼️ Image & Media Tools
- **CDN Image Uploader** - Upload and manage images with CDN integration
- **Image Text Extract Tool** - Extract text from images using OCR

### 💻 Development & Utility Tools
- **Text Compare Tool** - Compare and highlight differences between text blocks
- **IP Tracker** - Lookup and track IP address information
- **Deals API Amazon** - Browse and track Amazon deals via API

### 🎥 Communication & Streaming
- **WebRTC v0** - Web Real-Time Communication (basic version)
- **WebRTC v1** - Web Real-Time Communication (enhanced version)
